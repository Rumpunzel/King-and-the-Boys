# Lit Tiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wall torches, braziers and candles become host-decided tile state: torches and braziers widen the sight of heroes standing in their light, and lit tiles show from afar along passages.

**Architecture:** A `TileLight` resource describes a kind of wall light (its props, the `LightSource` heroes standing in it get, whether it lights the tiles opening onto its own). The host rolls each tile's light as it spawns the tile and sends it in the structure's spawn data (saved with it); decorations show it. `Level` adds tile lights to a hero's sight lights (`Character.get_vision()`) and reveals lit tiles within a beacon reach along the existing sight paths.

**Tech Stack:** Godot 4.6, typed GDScript (strict warnings), gdUnit4.

**Spec:** `docs/superpowers/specs/2026-11-14-lit-tiles-design.md`

## Global Constraints

- Beacon reach: 6 cells (a level setting, `Level.beacon_reach`, default `6.0`).
- Standing in light: the hero's own tile or a tile with a passage to it (`Level.is_passage`); torches and braziers give the held torch's `LightSource` (`data/equipment/light_sources/torch.tres`: +1 vision, +1 darkvision); a `LightSource` counts once.
- Candles: no `LightSource`, light only their own tile.
- Never around corners: beacons reveal only cells in `Level.get_cells_in_sight(from, beacon_reach)`.
- The roll is seeded like monsters: `hash([generation_random.seed, cell, &"light"])`, only on tiles whose profile has `decorations` with `tile_lights` and at least one closed side, by `TileDecorations.light_chance`.
- Strict typing; every new `class_name` gets an `@icon` (`TileLight` shares the lights' yellow `uid` of `tools/icons/yellow/lantern-flame.svg`); references by `uid://`; new `.gd` files commit their `.uid` (rescan with `--import`, editor closed); tests reference resources by uid with the path in a comment.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
